User Requirements for Gue Smart Farms Limited E-Commerce Platform
Project Overview
The proposed system is an integrated Farm E-Commerce Platform for Gue Smart Farms Limited designed to facilitate the online sale and purchase of farm products, livestock, and related agricultural services. The platform should support both direct sales by the company and a marketplace feature where external users can advertise and sell their livestock and poultry products.
The system should be user-friendly, mobile responsive, secure, and capable of supporting future scalability.
1. Core Features and Functional Requirements
A. Product Catalogue/Menu Management
The platform should provide categorized menus for all available farm products and livestock.
1. Egg Sales Module
The system should provide two purchase categories for eggs:
a. Retail Purchase
•	Quantity: 5 crates and above
•	Intended for retailers and bulk buyers
b. Household Purchase
•	Quantity: 1–4 crates
•	Intended for home and personal consumption
Functional Requirements
•	Users should be able to:
o	Select quantity
o	View price per crate
o	Add to cart
o	Proceed to checkout
•	Admin should be able to:
o	Update pricing
o	Manage stock availability
o	Set promotional pricing
B. Chicken Sales Module
The system should provide a dropdown or selection option for chicken purchase categories, with all chicken sales measured and sold in kilograms (KG).
Chicken Categories
a. Full Chicken
Whole processed chicken sold per kilogram (KG)
b. Chicken Parts
Users should be able to select specific chicken parts sold in kilograms (KG), including:
i.	Chicken Breast
ii.	Drumstick
iii.	Wings
iv.	Thighs
v.	Head and Feet

Functional Requirements
The system should:
•	Display price per kilogram (₦/KG)
•	Allow users to:
•	Select preferred chicken category or part
•	Input desired weight/quantity in KG
•	View automatic price calculation based on selected weight
•	Add items to cart
•	Proceed to checkout
•	Automatically calculate:
•	Total weight
•	Unit price
•	Total payable amount
•	Support:
•	Inventory management by weight
•	Real-time stock updates
•	Delivery and packaging preferences
Example
•	Chicken Breast = ₦6,500/KG
•	User selects 3KG
•	Total = ₦19,500
•	The admin should also be able to:
•	Update price per KG
•	Manage available stock by weight
•	Enable or disable specific chicken parts
•	Configure promotional pricing and discounts

C. Cow Sharing System
The platform should support a cow-sharing feature, especially for festive or group purchases.
Sharing Options
1.	Full Slot
2.	Half Slot
Functional Requirements
•	Display available cows
•	Show:
o	Estimated weight
o	Price per slot
o	Number of remaining slots
•	Allow multiple users to participate in a single cow purchase
•	Automatically close booking once all slots are filled

D. Whole Livestock Sales
The system should support the sale of whole animals including:
•	Cows
•	Rams
Functional Requirements
•	Animal profile page should include:
o	Breed
o	Weight
o	Age
o	Health condition
o	Price
o	Images/videos
•	Buyers should be able to:
o	Reserve
o	Purchase directly
o	Contact seller/admin

2. Marketplace Feature (User-to-User Sales)
The platform should allow registered users to advertise and sell their own livestock and poultry products.
Supported Listings
Users should be able to advertise:
•	Chickens
•	Cows
•	Rams
•	Other farm animals
Seller Listing Requirements
Users should provide:
•	Animal type
•	Breed
•	Weight
•	Age
•	Health condition
•	Price
•	Location
•	Geo tagged Images/videos
•	Contact details
3. Commission System
Gue Smart Farms Limited should earn commission from every successful marketplace transaction.
Commission Requirement
•	The platform should automatically deduct 5% commission from the final selling price.
Example:
If a seller lists an animal for ₦100,000:
•	Seller receives: ₦95,000
•	Platform commission: ₦5,000
4. Auction/Competitive Bidding Feature
The system should support an auction-based buying system where buyers can place competitive bids on animals.
Auction Functional Requirements
•	Sellers can choose:
o	Fixed Price Sale
o	Auction Sale
•	Auction listings should include:
o	Starting bid
o	Auction end date/time
o	Current highest bid
•	Users should:
o	Place bids
o	Receive notifications when outbid
o	See countdown timers
•	System should automatically declare the highest bidder as winner when auction closes
5. User Management System
User Roles
The platform should support:
1.	Admin
2.	Buyers
3.	Sellers
4.	Delivery/Logistics Personnel (optional future feature)
Authentication Features
•	User registration
•	Login/logout
•	Password recovery
•	OTP/email verification
6. Payment Integration
The platform should support secure online payments through:
•	Bank transfer
•	Debit/Credit cards
•	Wallet/payment gateways
Additional Features
•	Payment confirmation
•	Transaction history
•	Invoice generation
•	Refund management
7. Delivery and Logistics
The system should support:
•	Delivery scheduling
•	Delivery fee calculation
•	Order tracking
•	Pickup options
8. Admin Dashboard
The admin dashboard should allow management of:
•	Products
•	Users
•	Orders
•	Auctions
•	Commissions
•	Reports and analytics
•	Inventory
•	Payment records

9. Notifications System
The platform should send notifications through:
•	SMS
•	Email
•	WhatsApp (optional future integration)
•	In-app notifications
Notifications should cover:
•	Order confirmation
•	Payment confirmation
•	Auction updates
•	Delivery status
•	Seller approvals

10. Technical Requirements
The platform should:
•	Be mobile responsive
•	Support Android and iPhone devices
•	Have fast loading speed
•	Include secure authentication and data protection
•	Support future mobile app integration
•	Be scalable for future expansion
11. Future Expansion Features (Optional)
Potential future features may include:
•	Live livestock video inspection
•	AI-based livestock price estimation
•	Veterinary consultation booking
•	Farm equipment marketplace
•	Subscription services
•	Affiliate/referral system
•	Multi-vendor support
